CANAL WEBSOCKET

Conéctate a /ws

La conexión comienza con un evento conexion. Después, las operaciones HTTP publican eventos con tipo, acción y datos. Los mensajes entrantes se responden como mensaje_recibido; el control del vehículo se valida mediante la API HTTP.

URL DE CONEXIÓN
ws://localhost:8000/ws
EVENTO DE BIENVENIDA
